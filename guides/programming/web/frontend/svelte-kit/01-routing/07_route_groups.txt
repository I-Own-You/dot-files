1. sometime you want additional logic but without breaking the routes, like a wrapper guard,
   as "+layout.svelte" adds common UI, "+layout.server.ts" can be a common route group logic


2. "src/routes/(auth)account/+page.svelte"
   "src/routes/(auth)app/+page.svelte"

   accessing both "/account" and "/app" must go through (auth) route guard

2.1 in "src/routes/(auth)/+layout.server.ts":
            import { redirect } from '@sveltejs/kit';

            export function load({ cookies, url }) {
               	if (!cookies.get('logged_in')) {
              		redirect(303, `/login?redirectTo=${url.pathname}`);
               	}
            }
