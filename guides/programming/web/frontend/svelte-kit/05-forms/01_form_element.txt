1. <form> element is used when you need to send data from browser to a server rather than reverse

2. in "+page.svelte" you will have something like this:
        <form method="POST">
           	<label>
          		add a todo:
          		<input
         			name="description"
         			autocomplete="off"
          		/>
           	</label>
        </form>

        when you hit "enter" you will get an error since you didnt define a "server action" which
        will handle the form request

2.1 in "+page.server.ts" you would have the server action like this:
        export function load({ cookies }) {
           	// some code
        }

        export const actions = {
            // 1. notice the "default" property name, this means every form request will be handled,
            //    by this server action (not good actually)
            // 2. "request" property inside { } is of type Web API Request (browser one)
           	default: async ({ cookies, request }) => {
          		const data = await request.formData();
          		db.createTodo(cookies.get('userid'), data.get('description'));
           	}
        };

        1. now, when you hit enter for the form, code inside actions.default will execute and the page
           reloads with the new "data", btw "data" here is not the variable define "const data = ...",
           its the props "data" inside "+page.svelte"
        2. another thing is that we didnt write any "fetch" code or used any JS code, in fact
           this code will work even without JS itself since we use <form> element which works
           without JS
