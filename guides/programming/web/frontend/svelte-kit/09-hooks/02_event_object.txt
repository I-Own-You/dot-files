1. "event" from "handle" hook is the same object as an instance of RequestEvent from @svelte\kit
   that is passed into api routes in:
        1. "+server.ts"
        2. form actions
        3. "+page.server.ts"
        4. "load" functions in "+page/layout.server.ts"

1.1 it has a lot of useful properties, one of them is "locals" property where you can
    store any arbitrary data to retrieve it later somewhere

2. in "src/routes/hooks.server.ts":
            export async function handle({ event, resolve }) {
               	event.locals.answer = 42;
               	return await resolve(event);
            }

2.1 in "src/routes/+page.server.ts"
            export function load(event) {
               	return {
              		message: `the answer is ${event.locals.answer}`
               	};
            }
