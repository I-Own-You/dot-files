1. "handleError" hook lets you catch some errors and do some action

2. default look for this hook is like this in "src/hooks.server.ts":
        // as you noticed, this is the unexpected error hook for
        export function handleError({ event, error }) {
           	console.error(error.stack);
        }

2.1 the console will be on server, not browser, on browser the error will fall back to:
    1. "page.error" for "+error.svelte"
    2. %sveltekit.error% in "src/error.html" will be just:
        1. { message: 'Internal Error' } for 500
        2. { message: 'Not Found' }  for 404

2.2. if you want to change this behaviour and something, for example return some new data
     for the error to be available, you would do this, in "src/hooks.server.ts":
            export function handleError({ event, error }) {
               	console.error(error.stack);

               	return {
              		message: 'everything is fine',
              		code: 'JEREMYBEARIMY'
               	};
            }

2.3 in "src/routes/+error.svelte":
            <script lang="ts">
               	import { page } from '$app/state';
            </script>

            <h1>{page.status}</h1>
            // noticee the new data used through the same "page.error"
            <p>{page.error.message}</p>
            <p>error code: {page.error.code}</p>
