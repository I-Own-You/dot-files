1. your envs in .env, .env.local, .env.prod, .etc (look for vite config) can be read
   by svelte-kit

2. in ".env": HELLO="hello"

2.1 in "src/routes/+page.server.ts":
    import { PASSPHRASE } from '$env/static/private';

2.2 importing $env/static/private inside public things like "src/routes/+pages.svelte"
    is not allowed by svelte-kit and will show you an error if you do so

2.2.1 $env/static/private variables can appear only inside:
        1. "+page/layout.server.ts"
        3. "+server.ts"
        4. any module(js file with type:module) ending in ".server.ts"
        5. any module inside "src/lib/server"

2.3 $env/static/private, the "static" part means the environment variable must be known
    at build time, and then can be replaced to not be available after build:
        import { FEATURE_FLAG_X } from '$env/static/private';

        if (FEATURE_FLAG_X === 'enabled') {
           	// code in here will be removed from the build output
           	// if FEATURE_FLAG_X is not enabled
        }
