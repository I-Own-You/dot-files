# kanata
1. go here: https://github.com/jtroo/kanata/releases
2. download windows version zip file (x64)
3. download the interception driver(it will be a folder with .exe in it) from there "copy in this repo" link
4. put content from 2 and 3 step inside same folder under any folder, like $env:USERPROFILE\Apps\kanata
5. install interception driver from interception folder downloaded from step 2 with "/install" argument without ""
6. restart
7. copy interception.dll from interception folder you downloaded: "Interception\library\x64\interception.dll" into kanata folder you created on 4 step
8. copy kanata.kbd file from $env:USERPROFILE\dot-files\windows-post-install into folder from 4 step
9. make kanata launch on startup:
   1. crete a shortcut of kanata_windows_gui_wintercept_x64.exe file
   2. take kanata shortcut and put inside: C:\Users\mkc\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
10. restart
